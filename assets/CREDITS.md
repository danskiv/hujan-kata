1. **Jangan** pakai gambar/karakter berhak cipta (Skibidi, karakter game lain, dll.)
2. **Konsep/istilah** (hewan, buah, warna) bebas digunakan

4. Simpan bukti lisensi tiap aset (screenshot halaman lisensi)
